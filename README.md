# 中英化学速查桌面（离线版）

一个**单文件、零联网**的中英双语化学速查工具。双击 HTML 就能用，不需要安装、不需要服务器、不发送任何数据。

面向的是高中到大学预科阶段的化学学习（中国高中 / A-Level / IB / AP 的内容都在里面），中英对照，方便同时应付中文考试和英文教材。

---

## 为什么是"单文件"

所有数据、样式、脚本（包括公式排版库和三维分子库）都内嵌在这一个 HTML 里；中文使用系统字体，不内嵌字体文件：

- **完全离线**：页面不含任何外部引用（无 link、无 @import、无外链 url()），运行时零网络请求。可在浏览器开发者工具的 Network 面板里断开网络后刷新验证：功能不受影响（页脚里的参考链接除外，那些是需要联网的外部链接）。
- **可携带**：拷到 U 盘、发到微信、丢进任何网盘都行，不会因为对方没装环境而失效
- **不会过期**：不依赖任何在线服务，不存在"网站挂了就用不了"
- **可以直接提交/备份**：一个文件就是一个完整的资料库

代价是文件比较大（约 2.3 MB）。打开速度取决于设备与浏览器：在作者的 Mac（Chrome）上实测"页面就绪"约 150–170 毫秒，其他设备请以实际体验为准。

## 里面有什么

按导航分成六组，共 19 个板块：

**01 数据速查**
- 元素周期表：118 个元素的中英名称、读音、原子量、电子排布、电负性、电离能、熔沸点、氧化态，外加三种原子半径（经验／共价／范德华）与离子半径
- 离子团速查（30 种常见离子）
- 溶解性表（72 格）
- 俗名对照（烧碱、胆矾、干冰…中英名称与化学式）
- 放射性核素与半衰期：20 种常见放射性核素 + 84 个元素 288 条天然同位素丰度，带半衰期计算器与碳-14 测年

**02 命名与规律**
- 英文化学命名（18 条规则，含有机与配合物命名）
- 性质与易错点 + 三张交互式周期性趋势图（可悬停读数、拖动放大）

**03 反应与计算**
- 离子方程式速查（51 条，公式化排版，可单条复制）
- 有机反应与鉴别（25 条 + 16 个分子的二维结构式 + 21 个分子的**可旋转三维结构**）
- 摩尔／浓度计算 + **化学方程式自动配平器**
- 酸碱 pH 速查
- 电化学（标准电极电势、原电池与电解池）
- 热化学：92 种物质与 26 种水合离子的标准生成焓 + **反应热计算器**

**04 实验与检验**
- 检验与颜色（58 条：离子检验、气体检验、焰色反应、常见颜色）
- 实验室安全：59 种常用试剂的 GHS 危险分类（象形图 + 信号词 + 中文危险语句）
- 红外光谱：18 条官能团特征吸收 + 10 个化合物的实测峰位对照 + 读谱步骤

**05 练习与记忆**
- 易混对照（9 组）
- 遮答案练习
- 生词本 + 间隔重复复习（FSRS 算法，与 Anki 同源）

**06 参考**
- 术语表（151 条）
- 课程对照

其他：全文搜索（支持中英文、化学式、俗名、元素符号与拼音，命中处高亮，元素表格子会跟着过滤）、深浅色主题、缩放、打印样式、公式一键复制。

## 怎么用

1. 下载 `化学速查桌面_离线版.html`
2. 双击，用现代浏览器打开（开发与测试环境为 Chrome；其他浏览器未逐一实测，若发现问题欢迎反馈）
3. 顶部搜索框可以搜中文名、英文名、化学式、离子、俗名——比如搜"苏打""SO4""+3"都能命中

三维分子需要浏览器支持 WebGL。若设备不支持，页面会显示一句提示，其余功能不受影响（这条降级路径已实测）。公式排版使用内嵌字体与 KaTeX，不依赖联网。

## 已知限制

- 化学方程式配平器对**多原子离子**需要显式写出电荷，例如写 `SO4^2-` 而不是 `SO42-`；左右两边用 `->`、`=` 或前后带空格的 `-` 分隔都行
- 红外数据是**气相谱**，峰位比液膜/KBr 压片高 20–60 cm⁻¹，使用时注意相态
- 部分超重元素没有标准原子量，页面如实留空；7 种低危险试剂 PubChem 未收录 GHS 分类，页面显示"未收录"而不是编一条
- **打印／导出 PDF 只输出当前正在看的那个板块**（不是全部 19 个），要打印别的板块请先切过去
- 天然同位素丰度中有 9 个值（Ce、Yb、Hf 的若干同位素）与 IUPAC 最新值有 0.001–0.14 个百分点的差异，这些元素的天然丰度本身随样品波动
- 化学式里元素右下角的个数上限为 999，超出会提示而不是硬算
